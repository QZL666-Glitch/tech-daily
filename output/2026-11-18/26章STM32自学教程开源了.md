# 26章STM32自学教程开源了

*来源：GitHub · 2026-11-17*

**引言**
在嵌入式开发的学习路径上，STM32几乎是绕不开的一站。但很多初学者卡在同一个地方：资料太散。寄存器手册厚得像砖头，视频教程看完就忘，例程跑通了却说不清为什么。GitHub 上有一个名为 zhuguang-ZFG/STM32 的开源项目，试图用一套结构化的方式解决这个问题——它提供了一份 26 章的零基础自学教程，覆盖从 GPIO 到低功耗的完整知识链路，并配有 B 站视频和公众号连载。项目目前获得 18 颗星，规模不大，但内容组织方式值得一看。
## 教程覆盖了什么
这套教程的知识地图相当完整。基础部分从 GPIO（通用输入输出口，也就是芯片上能读能写的引脚）起步，依次讲串口通信、时钟树（芯片内部各模块的时钟分配关系）、中断、PWM（脉宽调制，用数字信号模拟模拟量输出）、ADC（模数转换，把电压变成数字）、I2C 与 SPI（两种常见的板级通信总线）、DMA（直接内存访问，让数据搬运不占用 CPU）以及低功耗模式。这条路线基本对应了 STM32 开发中最常打交道的片上外设，顺序也符合由浅入深的认知规律。
值得注意的是，教程明确以 HAL 库加 STM32CubeMX 为主线。HAL 库是 ST 官方提供的硬件抽象层，把寄存器操作封装成函数调用；CubeMX 则是图形化配置工具，点选即可生成初始化代码。对零基础学习者来说，这条路线能显著降低起步门槛——不必一上来就啃参考手册里的位定义。
## 配套资源与工程细节
项目不只是文字。素材显示，教程配有 B 站视频和公众号「SIAI小宇宙」的连载，形成文字加视频的双通道学习材料。此外还包含“避坑清单”和可运行例程——前者对自学者尤其实用，因为嵌入式调试中大量时间消耗在环境配置、时钟没使能、引脚复用冲突这类非知识性问题上。
从仓库标签看，项目涉及 STM32F103 和 STM32H7 两个系列，前者是经典的 Cortex-M3 入门芯片，后者是性能更高的 Cortex-M7 平台，说明教程在芯片选型上有一定的跨度覆盖。标签中还出现 bare-metal（裸机，即不跑操作系统直接操作硬件）、firmware、iot 等关键词，指向的学习场景是底层固件开发而非应用层编程。仓库主语言标注为 Python，这通常意味着配套脚本或工具链中存在 Python 代码，而非教程本身用 Python 编写——考虑到主题标签全部围绕 C 与嵌入式，这一点需要读者留意区分。
## 适合谁，不适合谁
从内容结构判断，这套教程的定位是“零基础到能上手”的入门级材料，而非深入内核架构或实时操作系统的高级课程。26 章的体量足以覆盖常见外设的用法，但素材中未提及 RTOS、USB、以太网等进阶主题。因此它更适合刚接触 STM32 的学生、转岗工程师，或需要快速补齐 HAL 库使用能力的开发者。已经熟悉寄存器开发或需要做复杂系统设计的人，可能会觉得深度不够。
**小结**
开源教程的价值往往不在技术前沿性，而在组织方式与可复现性。这个项目把 26 章内容、视频讲解、避坑经验和可运行例程打包在一起，用 HAL 库与 CubeMX 降低了入门曲线，对自学者来说是一份省去资料筛选成本的选择。18 颗星说明它尚未被广泛验证，读者在使用时不妨以例程实测为准，遇到与手册不符之处以官方文档为最终依据。

- **CubeMX** → 图形化配置工具，点选即可生成初始化代码。
- **bare-metal（裸机）** → 不跑操作系统，直接操作硬件。

## 小白常见问题

**Q1：完全没学过单片机，能直接学 STM32 吗？**
可以，但要有心理准备。这套教程定位是“零基础到能上手”，走 HAL 库 + CubeMX 路线，避开了直接啃寄存器手册。不过“零基础”通常指没接触过 STM32，而非完全不懂 C 语言和基本电路常识。建议先确认自己能看懂简单的 C 函数和变量定义，再开始 GPIO 章节。

**Q2：HAL 库和寄存器开发，我该学哪个？**
入门阶段建议先 HAL 库。它把位操作封装成函数，能让你快速跑通外设、建立信心。但 HAL 不是“不用懂硬件”，学到一定程度仍需回看参考手册理解时钟、复用等概念。已经熟悉寄存器开发的人，这套教程可能深度不够——文中也明确说了它更适合入门者。

**Q3：学 STM32 一定要买开发板吗？**
文中未说明具体硬件要求。通用经验是：需要一块对应芯片的开发板（如 F103 系列）配合例程实测，因为嵌入式调试大量问题出在硬件连接和时钟配置上，纯看视频很难真正掌握。具体型号以教程例程和官方最新说明为准。

**Q4：教程里的 F103 和 H7 我该选哪个？**
F103 是 Cortex-M3 经典入门芯片，资料多、成本低，适合打基础；H7 是 Cortex-M7 高性能平台，适合后续进阶。文中未说明两系列章节如何分配，建议从 F103 起步，具体以教程目录和官方最新说明为准。
